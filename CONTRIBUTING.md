# Contributing

Report bugs and request features at https://github.com/gavinsimpson/cocorresp/issues.
Include a minimal reproducible example, expected and observed behavior, and
`sessionInfo()`. Use synthetic or shareable data where possible.

For code changes, open a focused pull request from a feature branch. Follow
DEVELOPMENT.md, add regression tests, update Markdown roxygen and NEWS, and run
the test suite and package checks. Explain numerical changes with a reference
calculation or reproducible example. Preserve existing public APIs unless a
change has been discussed with the maintainer.

The maintainer reviews contributions as time permits; no response-time guarantee
is offered. Questions about usage are welcome in the issue tracker. Contributions
are distributed under the package's GPL-2 licence. Follow CODE_OF_CONDUCT.md.
